# Example dashboards

Place example code-diff dashboards for this skill in this folder.

They are kept locally and ignored by Git (see `.gitignore`) because a rendered
diff embeds real source from a private repository. This README and `.gitignore`
are tracked so the folder and its purpose stay visible.

`reference-dashboard.html` (local only) is a representative output: side-by-side
annotated diff, a two-column call-flow diagram, and Go syntax highlighting.
